Stillfeed is a Bun + TypeScript application with a React UI; there is no Python. SQLite (bun:sqlite) is the only runtime state: articles, seen marks, saved items, sources, X accounts, settings, feed batches, Hot picks, suggestions, cached readings and summaries, model decisions.

Server and processes: src/server.ts serves the API and the UI, schedules collections internally (src/server.ts nextRefresh; every N hours with an optional 23:00–05:00 night pause) and spawns two children: a collection (`--collect`, src/collect.ts) and the reader worker (src/reader_worker.ts), which downloads and sanitizes articles and batches summaries. Web requests only read cached preparation results or enqueue high-priority jobs; never run a model in an HTTP handler. Saved items are exempt from retention, including their cached content.

Collection (src/collect.ts): RSS/Atom/JSON feeds (src/feeds.ts), YouTube channels through youtubei.js (src/youtube.ts), X through SocialData (fetchTweets, records in src/tweets.ts) and nine web collectors (src/web.ts) run side by side, then classify(): trusted AI sources, the keyword filter (src/relevance.ts), the data-engineering signal, and the model triage (src/triage.ts, decisions cached in model_decisions). Phase timings are logged as 'timing <phase>'. Hot and suggestions run after a collection and must never fail it.

AI (src/llm.ts): one complete(prompt, role) for Anthropic (@anthropic-ai/sdk, server-side fallback for the families that support it), OpenAI-compatible APIs (openai) and the codex CLI. No provider means Unavailable: articles are still prepared, summaries/Hot/suggestions stay off. Prompts write in STILLFEED_LANGUAGE; summaries are cached per content hash and language. Configuration is src/config.ts (STILLFEED_HOME/.env, environment wins); never print secrets.

Sources (src/sources.ts): defaults from feeds/follow.opml, feeds/channels.json and feeds/x-accounts.txt, plus the user's feeds.opml and x-accounts.txt, each added once (table seeded), so a removed or disabled source stays that way. The sidebar adds a feed, site (autodiscovery) or YouTube channel by URL.

UI: React (ui/main.tsx, ui/app.tsx, ui/card.tsx, ui/detail.tsx, ui/sidebar.tsx), interface strings in ui/i18n.ts. Before using UI SDK, read node_modules/@ui-sdk/react/docs/llms.txt and the relevant component docs; use its ready-made components. The only swipe is back from the detail, using motion's drag (dragControls started from onPointerDown after gestureAllowed, so controls and screen edges never start a drag); saving is the bookmark button with an Undo toast; pull to refresh uses plain touch events because it must cooperate with native scrolling. Keep touch-action pan-y pinch-zoom on #feed and #articlePage. Controls are monochrome (colour belongs to content); options live in a right-hand Drawer whose controls apply immediately. Releasing the drawer's scroll lock can move the page on phones, so keepReadingPosition restores the reading position on that one <html> style change. New data replaces the snapshot automatically only while the reader is at the top; further down a pill offers it.

Seen workflow: hideSeen is the default; a snapshot (batch) never changes under the reader. Seen items leave on the next fresh load (open, pull to refresh, return after 15 min); an opened article leaves on return and is remembered per snapshot (session.collapsed). Hot picks leave only when opened or dismissed, never by being on screen.

Verify with bun install --frozen-lockfile, bun run check, bun test src and bun run build; commit bun.lock and the generated assets/build/ and index.html (scripts/build.ts: code-split, content-hashed bundles served as immutable, stylesheet inlined). Keep the first paint small: the reader, settings and dialogs load lazily; bun run test:perf enforces the budgets. Browser tests (tests/ui.mjs) use an isolated state directory and a stub collection; never touch a real Stillfeed home in a test.
