# What I care about

Stillfeed's AI reads this file when it picks the Hot tab (the few things you should not miss) and when it
suggests new sources. Write freely, in any language. Changes apply from the next refresh.
Copy it to ~/.local/share/stillfeed/interests.md (or set STILLFEED_INTERESTS) and make it yours.

## Tell me right away
- New models and major versions from OpenAI, Anthropic, Google, Meta, Mistral and DeepSeek.
- Coding agents and developer tools: Claude Code, Codex, Cursor, MCP, new CLIs and SDKs.
- Useful new tools I can try today or use at work.
- Big changes to prices, limits or availability of services I use.
- Data engineering: dbt, DuckDB, ClickHouse, Iceberg, orchestration.

## Rather not
- Minor version bumps, marketing, opinions and jokes without new information.
- Startup funding and general business news, unless it changes what I use.
